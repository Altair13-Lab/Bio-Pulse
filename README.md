# BioPulse — Пульс экосистемы / Экожүйе тамыры

## Русский

Законченный локально запускаемый сайт школьного инженерного проекта. Физический прототип **не собран**, реальных измерений, результатов испытаний и обученной AI-модели **нет**. Сайт честно разделяет демонстрацию и планы.

Проект находится в отдельной папке `biopulse/`; QURYLO в родительской папке не изменён.

### Запуск

Нужны Node.js 22.12+ (проверено на 22.23.3) и npm. Все команды выполняются из папки `biopulse`:

```sh
npm install
npm run dev
```

Открыть **http://localhost:5174**. Порт отличается от QURYLO; `strictPort` не позволяет незаметно сменить его. API, аккаунты, платные сервисы, секреты и backend не требуются.

```sh
npm run build
npm run preview
npm test
```

Production-просмотр: **http://localhost:4174**. `dist/` — готовая статическая сборка. Для публикации достаточно статического хостинга. Страницы используют URL-фрагменты, поэтому серверные правила для SPA не нужны. Сайт не публиковался.

### Возможности

- Девять разделов: проект, демопанель, конструкция, архитектура, AI и ограничения, исследование, бюджет, материалы, команда.
- Полные словари **ҚАЗ / РУС** с одинаковыми ключами. По умолчанию казахский. Переключение меняет `html lang`, заголовок и description, сохраняется в localStorage и не сбрасывает период, паузу и выбранные ряды. Изменения языка не пересоздают данные.
- Детерминированная синтетическая серия, 5 минут между образцами, 1 час / 24 часа / 7 дней. Симуляция каждые 4 секунды добавляет один **синтетический** шаг; она не синхронизирована с реальным устройством или текущим временем. Вне демопанели и в live-режиме таймер не работает. Пауза и сброс доступны отдельно.
- Шесть показателей; у каждого графика собственные единицы и шкала. Ряды скрываются флажками. Пропуски — `null`, линии разорваны, таблица доступна клавиатурой. Последние записи таблицы имеют пагинацию; CSV содержит **весь** выбранный период и все поля.
- CSV: UTF-8 BOM, переведённые заголовки с техническими именами полей и единицами, `source=demo`, пустые ячейки для `null`, исходный `soilRaw`, флаги качества.
- Почва: условный относительный процент, не объёмная влажность. Звук: условная относительная энергия audioRms² в шкале 0–1, не дБ SPL; исходный RMS также сохраняется в CSV. Диапазоны демонстрации и проверки схемы не являются заявленной точностью датчиков.
- Three.js показывает реальную сборку `BioPulse_v2/assembly_reference.obj`: «Закрыт», «Задняя крышка снята», «Компоненты». Экран не снимается. Вращение, масштаб, клавиатура и сброс работают; при ошибке WebGL/OBJ показывается предоставленное цветное изображение и сообщение. Платы и проводка условные.
- Редактируемый бюджет с количеством, ценой и отдельным резервом. Деньги считаются в целых тиынах. Пустая цена отличается от введённого нуля; неполный итог явно помечается. Настройки сохраняются только в браузере; повреждённые данные и запрет хранилища обработаны.
- Доступны OBJ, архив 12 исходных STL с координатами и Python-исходником, BOM и инструкции. Отсутствующие GLB, STEP, PPTX и PDF не выдаются за готовые материалы.
- SVG-схема архитектуры, мобильное текстовое представление, план интервью/калибровки/испытаний, роли без вымышленных людей и правдивые статусы этапов.
- Системные шрифты с кириллицей, видимый фокус, семантические таблицы, `prefers-reduced-motion`, обработка ошибок разделов и отсутствия сети. Аналитики и внешних шрифтов нет.

### Переводы

Изменяйте `src/i18n/ru.ts` и `kk.ts`. Тип `TranslationKey` не позволяет пропустить ключ в казахском словаре; тесты сверяют наборы ключей. Технические имена модулей и полей протокола остаются оригинальными. Казахский текст подготовлен для демонстрации; профессиональная лингвистическая редактура не проводилась.

### Материалы и модель

Добавляйте материалы в `public/materials`, настоящий GLB — в `public/models/biopulse.glb`. Пути и переведённые названия указаны в **едином manifest** `src/config/materials.ts`. Для языковых документов доступны отдельные пути. При старте Vite и сборке `vite.config.ts` проверяет реальные файлы в `public`. После добавления файла **перезапустите Vite или пересоберите**: только тогда появится рабочая кнопка.

**GLB не используется.** Импортируется правильный OBJ от 12 октября. Его исходные миллиметровые координаты X (ширина), Y (высота), Z (глубина от передней панели) не изменены. Для правостороннего 3D-отображения Z направлен в обратную сторону, масштаб сцены — 0,01 единицы на мм. Основной корпус: **высота 180 × ширина 120 × глубина 80 мм**, с круглым экраном около 250 мм по высоте. Задняя крышка с четырьмя M3 и седлом стойки снимается назад; верхний экран остаётся на основном корпусе. Платы ESP32 DevKit (без неподтверждённой версии), ESP32-CAM, датчики, провода и крепёж — упрощённые визуальные дополнения. Посадки и пересечения электроники физически не проверены. Ошибочный `BioPulse_Assembly.glb` не копировался.

### Будущий источник данных

`src/data/adapter.ts` разделяет demo/live. Live сейчас всегда возвращает `status: 'not-connected', rows: []`, ничего не запрашивает и не имитирует соединение. `src/lib/validation.ts` проверяет входное сообщение; ошибки возвращаются именами полей для обработки будущим адаптером. Это проверка формы/базовых диапазонов, не калибровка и не окончательная аппаратная спецификация.

```json
{
  "timestamp": "2026-10-01T12:00:00+05:00",
  "deviceId": "biopulse-01",
  "source": "live",
  "temperatureC": null,
  "humidityPct": null,
  "pressureHpa": null,
  "illuminanceLux": null,
  "soilRaw": null,
  "soilRelativePct": null,
  "audioRms": null,
  "qualityFlags": []
}
```

Для реального подключения нужны собранная схема и проверенная распиновка, прошивка и спецификация протокола, подтверждённые единицы и диапазоны, частота измерений, калибровка почвы/звука, политика флагов, часов и ошибок. Затем нужен настоящий транспорт и сервис хранения с обработкой переподключения, дубликатов и неверных сообщений. Изображения ESP32-CAM идут отдельным потоком. Никакой интеграции с железом пока нет.

### Проверки и ограничения

См. [VERIFICATION.md](VERIFICATION.md): production-сборка, 17 автоматических тестов, мобильные проверки обоих языков, реальный CSV и расчёт бюджета. В таблице наблюдений допустима прокрутка **внутри** области таблицы; горизонтальной прокрутки всей страницы нет. Сайт не кэшируется как PWA: без работающего локального сервера новый запуск невозможен; отсутствие интернета не мешает локальной работе.

## Қазақша

Бұл — мектеп инженерлік жобасының жергілікті жерде іске қосылатын дайын сайты. Физикалық прототип **әлі құрастырылған жоқ**. Нақты өлшемдер, сынақ нәтижелері және үйретілген AI-модель **жоқ**. Сайт демонстрация мен жоспарды анық ажыратады.

Жаңа жоба `biopulse/` бумасында орналасқан. Жоғарғы бумадағы QURYLO өзгертілмеді.

### Іске қосу

Node.js 22.12+ және npm қажет. `biopulse` бумасында орындаңыз:

```sh
npm install
npm run dev
```

Мекенжай: **http://localhost:5174**. API кілті, аккаунт, ақылы сервис немесе backend қажет емес.

```sh
npm run build
npm run preview
npm test
```

Production нұсқасын көру: **http://localhost:4174**. Статикалық жинақ `dist/` ішінде. Бөлімдер URL фрагменттерімен ашылады; SPA үшін серверлік бағыттау ережелері қажет емес. Сайт жарияланған жоқ.

### Не жұмыс істейді

- Жоба, демо-панель, құрылым, архитектура, AI шектеулері, зерттеу, бюджет, материалдар және команда бөлімдері.
- Толық **ҚАЗ / РУС** сөздіктері. Бастапқы тіл — қазақша. Тіл таңдауы сақталады, `html lang`, тақырып пен метадеректер өзгереді. Тілді ауыстыру график кезеңін, кідірісті және таңдалған қатарларды өзгертпейді.
- Бекітілген формула бойынша қайталанатын синтетикалық деректер. Аралығы — 5 минут; кезеңдер — 1 сағат, 24 сағат, 7 күн. Әр 4 секундта симуляцияға бір **синтетикалық** қадам қосылады. Бұл нақты құрылғы уақыты емес. Демо-панельден тыс және live режимінде таймер тоқтайды.
- Әр көрсеткіштің жеке шкаласы бар. Жоқ мәндер — `null`, график үзіліспен көрсетеді. Деректер кестесі пернетақтамен қолжетімді. CSV бүкіл таңдалған кезеңді қамтиды; UTF-8 BOM, аударылған тақырыптар, бірліктер, `source=demo` және бос ұяшықтар сақталады.
- Топырақ пайызы — шартты салыстырмалы шкала, көлемдік ылғалдылық емес. Дыбыстың салыстырмалы энергиясы — audioRms², шартты 0–1 шкаласы, дБ SPL емес. Бастапқы RMS CSV ішінде сақталады.
- Three.js берілген BioPulse v2 OBJ геометриясын көрсетеді: «Жабық», «Артқы қақпақ алынған», «Құрамдастар». Үстіңгі қалқан корпуста қалады. Бұру, масштаб, пернетақта және қалпына келтіру бар; WebGL/OBJ қатесінде түрлі түсті сурет пен түсіндірме көрсетіледі. Платалар мен сымдар шартты.
- Бюджет бағасыз басталады. Саны, бірлік бағасы және резерв бөлек есептеледі. Ақша бүтін тиынмен есептеледі. Бос баға нөлге теңестірілмейді; толық емес қорытынды белгіленеді. Баптаулар тек браузерде сақталады.
- OBJ, координаттары мен Python коды бар 12 STL архиві, екі тілдегі BOM және нұсқаулық қолжетімді. Жоқ GLB, STEP, PPTX және PDF дайын деп көрсетілмейді.
- Тәжірибелер мен сұхбат жоспары нәтижелерден бөлек берілген. Командада ойдан шығарылған есімдер жоқ. Дайын деп тек сайт демонстрациясы көрсетілген.

### Файлдар мен аудармалар

Жоба құрылымы жоғарыдағы тізімде берілген. Стильдер: `src/App.module.css`, тек CSS Modules қолданылады. Аудармалар: `src/i18n/kk.ts` және `ru.ts`; кілттері типпен және тестпен тексеріледі. Қазақша мәтін демонстрацияға дайындалды, кәсіби тілдік редактура жүргізілген жоқ.

Көрсеткіштердің баптауы — `src/config/metrics.ts`, бюджет — `src/config/budget.ts`. Деректердің генераторы — `src/data/demo.ts`, режимдер адаптері — `adapter.ts`. Кіріс хабарламаларды тексеру — `src/lib/validation.ts`.

### Материалдарды қосу

Материалдарды `public/materials` бумасына, нақты GLB-ді `public/models/biopulse.glb` жолына салыңыз. Бірыңғай тізім — `src/config/materials.ts`. Файлды қосқан соң Vite-ты **қайта іске қосыңыз немесе жобаны қайта жинаңыз**. Жүктеу батырмасы тек шынымен бар файлға беріледі.

**GLB қолданылмайды.** 12 қазандағы дұрыс OBJ импортталады. Бастапқы координаттар миллиметрде: X — ені, Y — биіктігі, Z — алдыңғы панельден артқа қарайғы тереңдігі. Оң қолды 3D көріністе Z кері бағытталған, масштаб — мм-ге 0,01. Негізгі корпус: **биіктігі 180 × ені 120 × тереңдігі 80 мм**; дөңгелек қалқанмен шамамен 250 мм. Төрт M3 бұрандасы бар артқы қақпақ пен тірек ершігі артқа алынады, қалқан корпуста қалады. ESP32 DevKit пен ESP32-CAM платалары, датчиктер, сымдар және бекіткіштер жеңілдетілген. Нақты платаларға қонуы мен электроника қиылысулары физикалық тексерілмеген. Қате `BioPulse_Assembly.glb` көшірілмеді.

### Нақты құрылғыны қосу үшін

Жоғарыдағы JSON — ұсынылған болашақ пішім. Жоқ мәндер `null` болады. Live адаптері қазір «Дереккөз қосылмаған» күйін және бос массив қайтарады; қосылымды елестетпейді.

Нақты жұмыс үшін құрастырылған схема, тексерілген түйіспелер, микробағдарлама, хаттама, бірліктер, диапазондар, калибрлеу, өлшеу жиілігі, уақыт пен сапа белгілерінің ережелері қажет. Одан кейін нақты тасымалдау және сақтау сервисін, қайта қосылуды және жарамсыз хабарламаларды өңдеуді енгізу керек. ESP32-CAM суреттері бөлек ағынмен беріледі.

Интернетсіз жергілікті жұмысқа сыртқы тәуелділік жоқ, бірақ сайттың өзін ашу үшін жергілікті сервер жұмыс істеп тұруы тиіс.
